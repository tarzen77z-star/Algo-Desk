# ALGO DESK

Robot traders dashboard, in the same look as AlphaScout — but only these two accounts:

- **New Main** — the regular robots
- **For AI** — Momentum and AI Analyst

AlphaScout is not in here — it runs on its own account, untouched.

Both accounts closed flat on Day 0, Mon Nov 2, 2026 — the starting line for the first Muse run.

Portfolio, transactions, and balances refresh weekdays at about 10:23 AM and 4:23 PM ET. AI scans update at about 8:50 AM, 11:23 AM, and 2:23 PM ET.

No account keys are stored in this repo. `data.json` is the snapshot behind `index.html`.
